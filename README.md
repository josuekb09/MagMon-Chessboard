# MagMon-Chessboard
♟️ MagMon Chessboard
Welcome to the MagMon Chessboard project. This is a custom-built, responsive chessboard created using pure HTML and CSS.

🤍The Story Behind the Name
The name MagMon is a tribute to the two most important people in my life:

Mag is for Magloire , my father. He was my biggest believer and the person who pushed me to follow my dreams. Though he is no longer with us, I build this to make his memory proud.

Mon is for Monique , my mother. She is my inspiration, and my dream is to use my success as a developer to provide her with the beautiful life she deserves.

This project isn't just about code; it's about a promise to my family.

🚀 Features
Professional Branding: Features a custom "MagMon" logo designed to represent the union of my parents' names.

Clean UI: Built with a classic wood-tone palette using hex codes #f0d9b5(Light) and #b58863(Dark).

Modern Layout: Utilizes CSS Grid for the board structure and Flexbox for perfect centering and responsiveness.

🛠️ Tech Stack
HTML5: Semantic structure for the game board.

CSS3: Advanced Grid and Flexbox layouts for a professional look.
